# Grapple

A 2D grappling-hook side-scroller: swing, wall-run and stomp your way across the city, then climb as high as you can in the endless bonus level.

Play it at https://jeremy6637.github.io/grapple/ (works on phones and desktop).

The whole game is a single self-contained `index.html` file.

## Grapple Zero-G

The sequel: steer a ship through an asteroid field using only two auto-targeting hooks. Hold the left or right half of the screen to hook, let go to fling.

Play it at https://jeremy6637.github.io/grapple/zero-g/ (built for phones in portrait; works on desktop too). It is also a single self-contained file, `zero-g/index.html`.
